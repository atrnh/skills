# Make instruction paths complete

Readers should be able to find the instructions that apply to them and follow the task through to its result. Organize differences around the work readers need to do.

- Distinguish differences that change the procedure from differences that only need a short qualification.
- Help readers identify their situation using observable checks. Do not assume they know the category names used to organize the documentation.
- Give each substantially different workflow a coherent path with its prerequisites and expected result.
- Keep shared explanation available without making readers assemble a procedure from scattered exceptions.
- Separate how content is maintained from how readers encounter it. Separate sources can still form one useful task experience.

A small variation does not require a separate guide or selector. Use the simplest presentation that keeps each path clear. Choose the presentation for the reader's task, without prescribing a particular interface or duplicating entire procedures unnecessarily.
