# Make the progression meaningful

A learning sequence should develop understanding. Each part should have a reason to follow the previous one and a purpose in the work ahead.

- Start with the learner's current knowledge and the questions the task is likely to raise.
- Give each section a clear contribution to the learning goal. Related topics alone do not establish a useful order.
- Order sections so that each one's prerequisites have already been taught.
- Make transitions explain the relationship between parts. Reorder the content when a transition cannot supply a missing logical connection.
- Read the sequence again as a learner and address unanswered questions that would block understanding or practice.

Learner questions help shape the sequence; they do not replace learning objectives or require answering every possible question. Deliberate exploration can leave questions open when resolving them is part of the learning experience.
