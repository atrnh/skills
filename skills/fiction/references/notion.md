# Notion comments

Read this only when posting or checking comments in Notion. Use the connected tools' current schemas and capabilities.

Before posting, fetch the page with discussion indicators and retrieve discussions on child blocks too. The comment tools return only page-level discussions by default, so a duplicate check without child blocks misses most existing feedback.

Post comments with the connector's comment tool, targeting the block that contains the passage. The connector attaches comments to whole blocks, not to phrases inside them, so quote the exact words each note concerns, as the [feedback guidance](feedback.md) describes.

After posting, fetch the discussions to confirm each comment's block and content.
